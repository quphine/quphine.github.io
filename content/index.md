Hey there! This is Prasanna Sakthivel, and you have reached by personal technical archive. I write about concepts that I find interesting—mostly in machine learning, but also across mathematics, signal processing and whatever else happens to catch my attention.

The goal isn't to collect polished tutorials or comprehensive textbooks. It's to work through ideas carefully enough that I can explain them to myself.

I learn best by trying to explain things. 


So these pages are partly notes, partly experiments and ocassionally attempts to answer questions that I probably should have stopped thinking about several hours ago.

If this helps someone else, then it is a nice side effect
